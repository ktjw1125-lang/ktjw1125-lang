# 안녕하세요! BSP Linux와 임베디드 시스템을 공부하는 개발자입니다 👋

Raspberry Pi 기반 BSP Linux부터 마이크로컨트롤러 프로젝트까지 경험하며, C와 Python을 바탕으로 임베디드 및 AI 분야를 꾸준히 학습하고 있습니다.

---

## 🐧 BSP Linux 학습·실습

- Raspberry Pi 부트로더(U-Boot), Linux 커널, 루트 파일시스템 구성 및 SD 카드 파일시스템 복구
- 디바이스 트리(DTS), 커널 모듈, 캐릭터 디바이스 드라이버 구현
- `mmap` 기반 메모리 제어와 저수준 입출력 실습
- FND, CLCD, DHT11 주변장치 제어 및 플랫폼 디바이스 드라이버 구현
- 디바이스 드라이버 커널 배포와 C++ / Qt 학습
